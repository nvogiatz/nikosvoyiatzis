CRM

The CIDOC Conceptual Reference Model is an ontology for cultural heritage information. It defines how people, objects, events and places are related through structured semantic relationships.

HERITAGE IS NOT AN OBJECT. IT IS A NETWORK OF EVENTS.

PROJECT OVERVIEW

Core Idea

CIDOC CRM models cultural heritage as a relational system where objects gain meaning through events, actors and temporal processes.

Focus

Events
Actors
Temporal relations

Use in Research

TV archives
Reconstruction
Postcustodial systems

Relevance

In audiovisual archives, CIDOC CRM helps describe not only the program but also production contexts, contributors, and reconstruction histories.
